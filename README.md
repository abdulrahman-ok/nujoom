# النجمات

تطبيق ويب للبنات على الآيباد. البيانات محفوظة في Firebase (مشروع nujoom-4de2f)، والتطبيق مرفوع على GitHub Pages.

## الملفات
- `index.html`: التطبيق كامل
- `sw.js`: يخلي التطبيق يفتح بدون إنترنت
- `manifest.webmanifest` و `icon-180.png` و `icon-512.png`: الاسم والأيقونة على الشاشة الرئيسية
- `firestore.rules`: قواعد الأمان. تنسخها في Firebase ← Firestore Database ← Rules

## الأمان
- المسؤول يدخل بإيميل وكلمة سر في Firebase، وهو الوحيد اللي يضيف البنات ويوافق على الأجهزة.
- أي جهاز جديد يرسل طلب موافقة، والمسؤول يوافق عليه أو يرفضه من الإعدادات، ويقدر يلغيه بعدين.
- قواعد Firebase تمنع أي جهاز ما انوافق عليه من قراءة البيانات.
- `firestore.rules` فيه `ADMIN_UID` مكان رمز حساب المسؤول. الأسهل تنسخ القواعد جاهزة من إعدادات المسؤول داخل التطبيق.
- الإعدادات المخفية: اضغط على كلمة "النجمات" ثانيتين.

## تحديث التطبيق
ارفع `index.html` الجديد مكان القديم على GitHub، وبعد دقيقة أو دقيقتين يتحدّث على الآيباد.
