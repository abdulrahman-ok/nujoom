# نجوم البيت

تطبيق ويب للبنات على الآيباد. البيانات محفوظة في Firebase (مشروع nujoom-4de2f)، والتطبيق مرفوع على GitHub Pages.

## الملفات
- `index.html`: التطبيق كامل
- `sw.js`: يخلي التطبيق يفتح بدون إنترنت
- `manifest.webmanifest` و `icon-180.png` و `icon-512.png`: الاسم والأيقونة على الشاشة الرئيسية
- `firestore.rules`: قواعد الأمان. تنسخها في Firebase ← Firestore Database ← Rules

## الأمان
كل عائلة لها رمز سري (٢٤ حرف) يتولّد تلقائياً، وتلقاه في ⚙️ إعدادات الأب.
القواعد ما تسمح لأحد يستعرض العائلات، فما أحد يوصل للنجوم إلا إذا عنده الرمز.
احفظ الرمز في مكان آمن.

## تحديث التطبيق
ارفع `index.html` الجديد مكان القديم على GitHub، وبعد دقيقة أو دقيقتين يتحدّث على الآيباد.
